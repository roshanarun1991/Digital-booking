# Digital Laundry Booking Demo

Static demo for a residential association laundry-room booking system.

Features:

- Registered-email demo login
- Four daily 4-hour booking slots
- One active booking per resident
- 30-minute reminder simulation
- Last-minute cancellation notifications
- Complaint/reporting flow
- English and Swedish language toggle
- 31-day slot overview
